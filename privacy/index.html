Privacy policy

Last updated October 3, 2026.

This website

christiangehrke.com is a personal site. It has no analytics, no advertising and no tracking cookies, and it doesn't ask you for any personal information.

  • Some pages remember small preferences (such as the season or day/night view) in your browser's own storage. They stay on your device and are never sent anywhere.
  • Videos are embedded from YouTube's privacy-enhanced domain (youtube-nocookie.com) and only load when you press play.
  • Like any web host, the server keeps standard access logs (address, page and time) for security and troubleshooting.

Studio and Google Drive

The site has a private, password-protected admin area called Studio, used only by me. Studio can read files from my own Google Drive with read-only access (Google Drive API, drive.readonly) so that photos and videos I upload there can be copied to this site's server and prepared for publishing.

  • It only ever reads my own Drive. It cannot change or delete anything in Drive.
  • Copied files are stored privately on this site's server and are published only when I choose to.
  • To help me write up a note, small copies of selected photos and my own notes may be sent to an AI service (Anthropic's Claude API) for drafting. That service doesn't use them to train models.
  • Google user data is never sold, never used for advertising, and never shared for any other purpose.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be removed at any time from the Google account's security settings (Third-party apps with account access).
